1|Introducción a PHP|cat1|PHP es un lenguaje de programación de código abierto especialmente diseñado para el desarrollo web. Es ampliamente utilizado y puede ser embebido en HTML, lo que lo hace muy práctico para crear páginas web dinámicas y aplicaciones web interactivas.
2|Fundamentos de JavaScript|cat2|JavaScript es un lenguaje de programación esencial para el desarrollo web moderno. Permite crear páginas web interactivas y dinámicas. Es el único lenguaje de programación que se ejecuta nativamente en todos los navegadores web modernos.
3|Bases de Datos MySQL|othercat|MySQL es uno de los sistemas de gestión de bases de datos relacionales más populares del mundo. Es de código abierto, rápido, confiable y escalable. Se utiliza ampliamente en aplicaciones web para almacenar y gestionar datos de manera eficiente.
4|Desarrollo Web Full Stack|cat1|El desarrollo Full Stack implica trabajar tanto en el frontend como en el backend de una aplicación web. Un desarrollador Full Stack debe conocer múltiples tecnologías incluyendo HTML, CSS, JavaScript, lenguajes del lado del servidor y bases de datos.
